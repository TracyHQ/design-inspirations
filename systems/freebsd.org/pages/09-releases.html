Release Information

FreeBSD releases are classified into Production Releases and Legacy Releases. For most users, production releases will be most suitable. Legacy releases are provided for existing users wishing to stay with a more conservative upgrade strategy.

Currently Supported

For information about branches, release dates, and estimated end-of-life (EOL) dates, please see the Supported Releases section of FreeBSD Security Information.
