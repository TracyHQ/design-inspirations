Why use Assistant in Grafana Cloud?

Grafana Assistant makes observability accessible through natural language. Understand telemetry, accelerate common workflows, and access AI-powered capabilities across Grafana Cloud without leaving the tools you already use.

Skip the learning curve and simplify your workflow

  • Get instant productivity with AI-assisted setup and workflows that cut onboarding time

  • Build complex queries and dashboards in seconds through a simple chat interface

Accelerate root cause analysis with agentic investigations

  • Stay ahead of incidents with early anomaly detection and correlation with Investigations

  • Quickly understand how issues spread across systems by leveraging the SRE agent and the Grafana Cloud Knowledge Graph

  • Get guided, prioritized next steps to resolve incidents faster

  • Automate routine triage so teams can focus on impact

Learn more about Investigations

Empower your entire team to take action

  • Unblock knowledge silos and empower teams to navigate complex systems with AI insights that reduce the need for deep domain expertise

  • Reduce cognitive load by automating routine tasks like incident summaries, log explanations, and error triage

Scale securely with the tools you already use

  • Enforce governance and human oversight at scale with role-based access (RBAC) for investigations, rules, and integrations—supporting EU AI Act expectations around access control, as well as US security frameworks like SOC 2

  • Operate within trusted compliance boundaries by running Assistant inside Grafana Cloud, supporting GDPR requirements in the EU, CCPA requirements in the U.S., and established security practices relied on by US enterprises

  • Work seamlessly across environments by using Assistant in Grafana Cloud, Slack, Microsoft Teams, and MCP-connected tools, so teams can investigate and collaborate while agents take action. Connect your self-managed Grafana instance with a one-click setup, or use Assistant via API or gcx CLI to extend workflows further.

AI in Grafana OSS

Grafana Cloud is the fastest path to value, but OSS innovation ensures flexibility for everyone. Connect your self-managed Grafana instance to Grafana Cloud with a one-click setup to use AI Assistant directly in your existing workflows. With our open source LLM plugin and MCP server, you can connect agents to Grafana and extend AI where you need it, without lock-in.

Extend AI across your stack with open integrations

  • One-click setup: Connect Grafana (OSS or Enterprise) to Grafana Cloud to use AI Assistant in your existing workflows

  • MCP support: Connect agentic tools to other data for richer context

  • OSS LLM plugin: Centralize keys, choose providers, and add “explain this” features across Grafana
