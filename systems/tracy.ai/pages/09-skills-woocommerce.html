How it connects

  • REST API keys

    A read-only consumer key to start — upgrade to write keys only when you enable write tools.

  • Through a stateless relay

    Open source (TracyHQ/tracy-mcp). Credentials ride each request — the relay stores nothing. Self-host it if you prefer.

  • Approval-first

    Write tools are off by default. Tracy proposes; you apply.

Proposes. Never surprises.

Refunds, price changes and stock edits are drafted as proposals with full context. You apply them — Tracy never moves money or inventory on its own.
